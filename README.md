# ✊ Rock Paper Scissors Game
 
A simple command-line **Rock Paper Scissors game built with Python**.
 
This beginner-friendly project allows the player to compete against the computer. The player selects Rock, Paper, or Scissors, while the computer randomly generates its choice. The program then compares both choices and determines whether the player wins, loses, or draws.
 
## 🚀 Features
 
- Play Rock Paper Scissors against the computer
- Choose between Rock, Paper, and Scissors
- Computer generates a random choice
- Displays ASCII art for each selection
- Automatically determines the winner
- Handles win, lose, and draw conditions
- Detects invalid numerical choices
- Simple command-line interface
 
## 🛠️ Technologies Used
 
- Python 3
- Python `random` module
- Conditional statements
- Lists
- Variables
- User input
- Integer conversion
- ASCII art
- Comparison operators
